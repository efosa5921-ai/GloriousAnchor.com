Glorious AnchorAdmin

Connect to your site

This page edits the files behind gloriousanchor.com directly in your GitHub repository. It needs a personal access token, which is saved only in this browser.

  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it Glorious Anchor admin, set an expiration (up to one year), and under Repository access choose Only select repositories → GloriousAnchor.com.
  3. Under Permissions → Repository permissions set Contents: Read and write and Actions: Read and write. Leave the rest.
  4. Generate, copy the token (it starts with github_pat_) and paste it below.
